## 3D Car Dealership Platform

An interactive car dealership web application designed to provide a modern virtual showroom experience. Users can browse available vehicles, view their specifications, and interact with **3D car models** to explore vehicles from different angles before making a purchasing decision.

### Key Features

* 🚗 Browse available car models
* 🧊 Interactive 3D vehicle visualization
* 🔄 Rotate and explore vehicles from different angles
* 📋 View vehicle specifications and details
* 🖥️ Responsive and modern user interface
* 🏪 Digital showroom experience
